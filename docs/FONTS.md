# Montserrat

Source: https://github.com/google/fonts/tree/main/ofl/montserrat
Font: Montserrat by The Montserrat Project Authors.
Licence: SIL Open Font License 1.1; full licence bundled at
`app/src/main/assets/licenses/Montserrat-OFL.txt`.

The regular (400), medium (500), semibold (600) and bold (700) resources are static
instances generated from the upstream weight-variable font using fontTools.
Static instances support minSdk 26 without requiring variable-font APIs.
No network font provider is used. All standard Material typography roles use
Montserrat; diagnostic log bodies intentionally remain monospace for readability.
